# SE2 Koozlet Project #

## Objectives ##
- Build a compete, database-driven app from scratch
- Add security to an application
- Persist, manipulate, and retrieve unique data tied to a user or quiz

## Description ##
We are building an app that allows users to develop and take quizzes. This project will allow a user to log in and make changes to their own quizzes along with creating study guides to better prepare for a course. There will be ways to search through quizzes based on authors or the various classes and or subject. A user will have a log of quizzes they have taken that keep track of the scores that they have taken in the past.

## How to Run
1. Run the following commands 
```
npm install -g jest
npm install
npm link jest
npm install -g prisma
npx prisma migrate dev --name init
node server.js
```
2. Access The URL
```
http://localhost:3000
```
